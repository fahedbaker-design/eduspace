# EduSpace

The offline teacher app of EduSpace (installable web app for iPad).
Course content and the students' pages stay online in Google Apps Script; this app keeps
course management and grading on the device and syncs when connected.

Current: prototype 0.3 (course colours in three tones) — after 0.2 — the approved style (soft cards, layered progress bars, pill tabs), the original EduSpace™ wordmark, the four-circle icon, IBM Plex Sans Arabic. Demo data with invented names. The first test page is test.html.
